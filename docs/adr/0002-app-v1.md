# ADR 0002 — App V1 : choix techniques

Statut : accepté · 05/11/2026

| Décision | Pourquoi | Plus tard |
|---|---|---|
| Carte = MapLibre GL JS dans une WebView (iframe sur le web), tuiles OpenFreeMap | Fonctionne dans Expo Go (test immédiat sur téléphone), même code iOS/Android/web, aucune clé d'API | MapLibre Native (dev build) si les performances l'exigent |
| MapLibre 5.x (build UMD) servi depuis notre site (`/vendor`), repli unpkg | La v6 n'est plus distribuée en UMD ; pas de CDN tiers par défaut (RGPD) | — |
| Données = base nationale IRVE → tuiles JSON 0,25° sur GitHub Pages, régénérées chaque nuit | Gratuit, sans backend, CORS ouvert, la position ne quitte jamais le téléphone | Tuiles 0,125° en zone dense ; base IRVE du PAN quand data.gouv retire l'ancienne (31/12/2026) via `IRVE_URL` |
| Paiement = Stripe Checkout (pré-autorisation) ouvert dans le navigateur de l'app | Pas de module natif → marche dans Expo Go et sur le web | PaymentSheet natif en dev build |
| Démarrage de charge = borne simulée | Aucun contrat eMSP signé en V1 ; l'app l'affiche clairement | Adaptateur eMSP marque blanche / OCPI Gireve derrière la même interface |
| Pas de compte utilisateur | Parcours en deux taps ; rien à protéger côté identité en V1 | OIDC (Keycloak/Zitadel) avec l'historique et la facture mensuelle |
